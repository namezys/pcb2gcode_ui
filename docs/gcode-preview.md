# G-code Preview

The G-code preview is a visual inspection aid for NC files generated by `pcb2gcode`.
It is not a machine simulator and does not replace controller verification or an air run.

## Parser and Interpreter

The app uses `gcodeparser` to parse G-code lines, then runs a small local interpreter
for the subset needed to draw flat movement traces.

Supported state:

- `G20` and `G21` for inch/metric units.
- `G90` and `G91` for absolute/incremental positioning.
- `Tn` for active tool tracking.
- `M6` as a recognized tool-change command with no motion effect.
- Modal `G0`/`G1` movement, including coordinate-only continuation lines.

Supported movement:

- `G0` / `G00`
- `G1` / `G01`
- X, Y, and Z coordinates.

## Cut and Retract Classification

Each linear segment is classified from the endpoint Z value:

- `Z < 0`: cut segment.
- `Z >= 0`: retract/travel segment.

Cut segments are drawn bright and above the Gerber preview. Retract/travel segments
are drawn as low-visibility dashed gray lines.

## Output Files

The Preview dialog reads NC files from the configured output directory and output
filename options:

- `front-output`
- `back-output`
- `drill-output`
- `milldrill-output`
- `outline-output`

Missing files are reported as preview warnings and do not block Gerber preview.

## Limitations

The first implementation intentionally ignores all commands except the movement and
state commands listed above. Unsupported commands are reported once per command.

Ignored commands include arcs (`G2`/`G3`), canned drilling cycles (`G81` and related
cycles), coordinate-system offsets, probing, spindle/coolant commands, dwell, and
controller-specific macros. If those commands materially affect the path, the preview
can be incomplete.
