# pcb2gcode-ui

Simple Flet desktop GUI for editing `pcb2gcode` parameters, saving canonical
`millproject` files, and generating NC files.

## Requirements

- macOS with `pcb2gcode` installed, for example:
  ```bash
  brew install pcb2gcode
  ```
- Python 3.14 or newer.

The app runs the `pcb2gcode` binary found on `PATH`. In this checkout it was verified with:

```bash
pcb2gcode --version
```

## Setup

```bash
python -m venv .venv
.venv/bin/python -m ensurepip --upgrade
.venv/bin/python -m pip install -e ".[dev]"
```

## Run

```bash
.venv/bin/python main.py
```

or:

```bash
.venv/bin/pcb2gcode-ui
```

## Workflow

1. Open an existing `millproject` or select Gerber/Excellon files directly.
2. Adjust parameters in the grouped tabs.
3. Save the `millproject`.
4. Validate settings.
5. Generate NC files.

The output directory defaults to `nc/` next to the first selected input file. You can override
it with the output directory picker. The app creates the directory if needed and overwrites
files generated by `pcb2gcode`.
